# APD_and_KPD_Model_Codes
Simulation and modeling codes for the atomistic (APD) and kinetic (KPD) probability distributions. The KPD applies the generally derived APD to a model system describing the random sulfonation of polyethylene (PE) and subsequent depolymerization to aqueous organic acid products.

The APD and KPD applied to modeling the sulfonated PE system are based on previous experimental work: https://doi.org/10.1021/acsapm.5c03616
